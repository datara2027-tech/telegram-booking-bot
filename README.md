# 📅 Telegram Booking Bot (free, open-source)

Готовый бот записи клиентов для малого бизнеса: салоны, мастера, репетиторы, автосервисы.

## Возможности
- Услуги, свободные слоты, рабочие дни — всё в одном config.json
- Клиент сам выбирает услугу → дату → время → оставляет контакты
- Владелец получает уведомление о каждой записи
- Отмена записей и экспорт в CSV

## Запуск за 3 минуты
```bash
npm install
BOT_TOKEN=ваш_токен node index.js
```
Настройки — в config.json (услуги, цены, график, adminId).
